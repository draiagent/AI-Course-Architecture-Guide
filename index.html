Level 1–5 課程能力地圖

課程不是堆工具，而是讓學員循序完成「提示 → 上下文 → 工作流 → Agent → AIOS」的能力升級。

Level 1
初階

提示詞工程

建立清楚指令、角色、目標與輸出格式。

  • Prompt 結構
  • 任務拆解
  • 輸出規格
Level 2
中階

上下文工程

讓 AI 讀對資料、理解限制並做出可信判斷。

  • Context Loading
  • 決策邊界
  • 證據驗證
Level 3
進階

工作流工程

將任務模組化、標準化並交由工具協作完成。

  • Skills
  • GitHub／Codex
  • 自動化流程
Level 4
高階

AI Agent 系統

建立可規劃、執行、驗證與反饋的智慧代理。

  • MCP／Tool Calling
  • Memory
  • Multi-Agent
Level 5
企業級

AI 作業系統

整合治理、安全、知識與跨部門流程，形成 AIOS。

  • Enterprise AIOS
  • 治理與稽核
  • 持續優化

Dataflow 資料流

把「內容被看見」到「形成課程報名與企業商機」串成一條可追蹤的資料鏈。

內容資料源Level 1–5、課綱、案例、影片
→
內容管理層Markdown／CMS／GitHub
→
前端呈現首頁、課程頁、圖卡、影片
→
使用者互動瀏覽、播放、下載、填表
→
事件追蹤來源、停留、CTA、轉換
→
名單與分眾初學者、講師、企業決策者
→
課程／顧問轉換報名、說明會、企業洽詢
內容流 互動流 轉換流

整合行銷漏斗

社群貼文不是終點，而是把受眾送進「認識—理解—信任—行動」的入口。

Awareness
短影音／Level 圖卡／議題型貼文
Interest
五級能力地圖、課程文章、直播
Trust
講師資歷、企業案例、實作成果
Action
留言關鍵字、下載、說明會、報名
Advocacy
作品分享、學員推薦、企業續約

核心行銷主張

「你以為會寫 Prompt 就會 AI？那只是 Level 1。」 以認知落差創造注意力，再用五級能力地圖建立專業權威， 最後將課程定位為一條從工具操作走向企業 AI 系統的升級路徑。
